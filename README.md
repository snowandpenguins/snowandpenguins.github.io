# Login design demo

An independent, nonfunctional HTML/CSS study of the Snapchat login page. **This is not Snapchat and is not affiliated with Snap Inc.**

The page has a prominent disclosure, a static example username, disabled buttons, and illustrative footer text. It has no form inputs, scripts, authentication integrations, analytics, cookies, browser storage, or credential collection. A restrictive Content Security Policy blocks scripts, connections, and form submission.

Open `index.html` directly, or serve the repository as static files. GitHub Pages should publish the `main` branch from `/(root)`. No custom domain is configured.

Visual reference: https://accounts.snapchat.com/v2/login (September 11, 2026). Snapchat's name and ghost mark belong to Snap Inc. The mark is reproduced for identification within this clearly labeled visual study; no ownership or endorsement is claimed. The CSS is independently written. System fonts are used, so typography can vary by device.
